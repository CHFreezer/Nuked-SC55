# SC-55 mkII 复音扩展 — 一页纸执行路线图

> 2026-09-11 冻结。细节/证据见 `mk2_polyphony_256.md`（§6.5 = 研究结果与勘误）与 `polyphony_256_todo.md`（R1-R20）。
> 本页是决策与执行入口；与旧章节冲突时以本页 + mk2 §6.5 为准。

## 0. 已定决策（2026-09-11）

| 项 | 决定 |
|---|---|
| 目标 | **容量 255**（`0xff` 哨兵 + 8-bit 池计数硬上限；与 256 无功能差异） |
| 机制 | **(ii)**：把碰 per-voice 数组的例程（26 逻辑/41 碎片）复制到 B 重写；A 只改入口跳转，本体零改动 |
| CLI | **`-voices:<n>`，范围 28–255 真生效**（单横线冒号，同 `-gain:`；`n=28` 即默认；n≠28 才建 B） |
| 参数化 | n 由 C 生成器（`MCU_PatchROM`）印进 B 的所有循环界与 config 字节（`config_reg_3d=n-1`）；数组容量固定 255 宽 |
| GT 公式 | 默认路径 `reg_slots=(config&31)+1` **不动**；扩展模式（flag 生效）`config+1`（勿用"第 7 位"判别式） |
| 效果槽 | 外置 `EFF_BASE`（默认 28；扩展 256..259；数组 **`[MAX_VOICE+5]`≥260**）；效果选择用 **PCM reg 0x3f 别名**（填 `EFF_BASE+(v&3)`，固件 1B patch `3e→3f`，效果簇留 A）｜采样节奏 `cycles` 钳 28（保 66207Hz） |
| 回归红线 | **无 flag = 与现状逐字节一致**；`-voices:28` 等价默认 |
| 验证矩阵 | 28（逐字节回归）+ 255（压力）必测；中间值（如 100）抽测参数化 |

## 1. 全景图

```
       磁盘 rom1.bin / rom2.bin（只读，不碰；SM 子 MCU 不碰）
                        │ 加载
                        ▼
   A = 原始 ROM 内存副本（A 本体保留；256 模式只把入口改跳转）
                        │
                        │  带 -voices:<n> 时 MCU_PatchROM 在内存里打补丁：
      ┌─────────────────┼──────────────────────────────┐
      │ ① config 字节    │ rom2 0x1432: c3 7b → c3 (n-1)│
      │ ② B 代码         │ rom2 空白区(cp=0x0E)：26 例程│
      │                  │ 255/n 重写 + 入口出口包装 +   │
      │                  │ 跨页蹦床 + IRQ handler 改写   │
      │ ③ B 数据(page6)  │ 数组 255 宽 + 256 位掩码暂存  │
      │ ④ 路牌(A→B)      │ 19 入口 + 0x45cbe + IRQ 向量  │
      └─────────────────┴──────────────────────────────┘
                        │
                        ▼
   固件(A+B) ──PCM 控制写──► GT 模拟器（src/）
                              mcu.cpp: page6(64KB) + 0xe800 窗口 + flag/patch 调用
                              pcm.* : 255 槽 / 256 位掩码×3 / EFF_BASE / 公式 / 节奏钳制
                        │
                        ▼
                   音频输出（n 个声部）
```

## 2. 改动面清单（改什么/为什么）

| 层 | 位置 | 改什么 | 为什么 |
|---|---|---|---|
| GT | `pcm.h` | 数组 255+4；mask/pending 32 字节 | 硬件 32 上限是模拟器写死的 |
| GT | `pcm.cpp` 写 | 低 32 位原窗口；新增 `PCM_WriteExt/ReadExt`（0xe800 高 224 位） | 掩码放不下原 64 寄存器 |
| GT | `pcm.cpp` DSP | `reg_slots` 模式开关；EFF_BASE 外置；`cycles` 钳 28 | 保效果器与采样率 |
| GT | `pcm.cpp` 通道 | `select_channel` 放开 0..n-1 + 效果扩展通道寄存器 | 28/29/30 被声部占用 |
| GT | `mcu.cpp` | page6 `b_ram`；0xe800 映射；`-voices` 解析；`MCU_PatchROM` 实现 | 扩展内存/接口/开关 |
| ROM | 配置 | `c3 <n-1>` | 告知 PCM 声部数 |
| ROM | B 代码 | 26 例程重写（r6/tp=6、page6 偏移、界=n、入口/出口中断包装、跨页蹦床、IRQ handler） | 只有 B 代码能访问 page6；8-bit 原界塞不下 |
| ROM | B 数据 | 255 宽数组（≈13KB）+ `MHI/PHI` 掩码暂存 | 原 SRAM 放不下 |
| ROM | 路牌 | 19 入口 + `0x45cbe` 改 4B `pjmp #0x0E`；IRQ0：`0x529` 原地 pjmp 或向量改指 B；效果 E 点 1B `3e→3f` | H8 同页 jmp 换不了 cp；IRQ/效果需按新语义改道 |
| 验证 | `tools/vm` | 镜像 PCM 变更（推荐） | 256 模式也要能 VM↔GT 对比 |
| 验证 | 工具 | 默认逐字节 diff；压力 MIDI | 红线与验收 |

## 3. 阶段与验收

- **阶段 0（收尾）**：R15（IRQ 通道号协议）/ R16（闭包静态补漏）/ R17（效果写入点全表）——可能改设计，先做；R18-R20 留到实现时。
- **阶段 1（GT 扩容，不碰 ROM）**：按 mk2 §6.5 R10 顺序实现；验收＝无 flag 逐字节一致 + 带 flag 时固件仍按 28 跑（容量惰性）。
- **阶段 2（B 块，小步搬）**：先 1 个例程跑通框架（补丁/跳转/page6/包装），再按闭包表搬；最后印界与掩码。每步在 `-voices:<n>` 下用 pcmtrace/快照验证。
- **阶段 3（验证）**：28 回归 + 255 压力 + 中间值抽测 + 性能实测。

## 4. 设计原则

1. **默认零回归**（红线）：一切新增在 flag 后；每步都测。
2. **A 零改动**：只挂路牌，可随时回退。
3. **B 自包含**：代码/数据/初始化都在 B；A↔B 只按寄存器约定交互。
4. **小步迁移**：一个例程一次，验证后下一个。

## 5. 阶段 0 结果与未决项

**已闭合（2026-09-11，mk2 §6.6）**
- ✅ R15：d15c=IRQ pending 标志；固件只需**下标完整**。方案：ext `0xe820` 完整 slot + `status&0x1f`；B handler 先读 ext 再 ack；落地 = `0x529` 原地 pjmp（22B）或 IRQ0 向量重定向（29B）。
- ✅ R16：全 ROM 静态扫描（含立即数基址）。闭包基本完整；**补 d1ac helper 族 4 入口**（`0x43695/0x436a3/0x436c3/0x436d5`）；B 必须**整例程本体搬运**（含未执行臂）。
- ✅ R17：66 写入点全表；效果簇不在闭包；**改用 PCM 0x3f 别名**——E 点原地 1B patch `3e→3f`，不需 0xe800 扩通道、不搬效果簇；6 个"读回"点同改；数组改 `[MAX_VOICE+5]`。

**未决（实现时）**
- R18 B 内 `@r6/@r7` page0 表访问全扫（随 B 重写逐例程）
- R19 中断屏蔽窗口时序影响（VM 实验）
- R20 性能与验收工具（阶段 3 前置）
