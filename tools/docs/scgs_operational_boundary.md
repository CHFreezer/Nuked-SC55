# SC-GS（Sound Canvas VSTi）DSP「工作边界」调研

对照对象：Nuked-SC55 的 `src/pcm.cpp`（Roland PCM ASIC 的逆向实现）
被调研对象：`C:\Program Files\Roland VS\SOUND Canvas VA\SCCore.dll`
日期：2026-09-05 ｜ 工具：`llvm-objdump` / `llvm-readobj`（`C:\Program Files\LLVM\bin`）
产物：本文件 + `sc.asm`（.text 全量反汇编，131,130 行）+ `scgs_filter.md`（滤波器专题）

> 「工作边界」指：DSP 数值在**到达格式/范围极限时如何处置**——字长、饱和、限幅、
> 溢出、量化、符号扩展、NaN/Inf。这正是 mk1 芯片（有 20 位饱和）与 mk2 hack
> （无饱和、32 位）产生差异的地方，也是本文的落点。

---

## 0. 结论速览

1. **SCCore.dll 的 DSP 是 float32（IEEE 754）**，不是芯片的 20 位定点。
2. **全 DSP 没有一处 SIMD 饱和**（无 `min/max/blend/packssdw`），限幅全部用
   **标量 `comiss` + 条件跳转**实现（`.text` 里有 **888 个 `comiss`**）。
3. **两个限幅域**：**±1.0**（归一化，`0x3F800000/0xBF800000`）与 **±16.0**（int32
   满量程，越界饱和到 `±0x7FFFFFFF/0x80000000`）。
4. **量化用 `cvttss2si`（截断，非四舍五入）**，内部用 **27 位定点**（scale≈2²⁷，
   `andl $0xfffffff`）做相位/索引。
5. **几乎无运行时 NaN/Inf 防护**：整个 DLL 只有 **1 个 `ucomiss`**，且在
   `TG_setSampleRate`（采样率变更 + NaN 守卫），不在每采样 DSP 里。
6. **滤波器**（`0x18008d9a0` / `0x18008ce70` 四变体）是**二阶双积分谐振低通**，
   拓扑与芯片一致，但**每采样不饱和**。
7. **对 mk2 爆音**：芯片 20 位在 **±524288** 频繁饱和（这是芯片音色的一部分）；
   mk2 hack 用 32 位（±2³¹）把边界抬高了 13 位却**没做饱和** → 高谐振时滤
   波器状态会越过芯片本会削掉的电平，**「缺失饱和」是强嫌疑**。详见 §6。

## 2. 数值格式（对照芯片 20 位）

| | 芯片（pcm.cpp） | SCCore.dll |
|---|---|---|
| 数据/样本 | **20 位** 二补码 `0x0..0xfffff`，符号位 `0x80000`，范围 **±2¹⁹=±524288** | **float32**，范围 ±3.4e38，~7 位十进制精度 |
| 内部定点 | 无（纯 20 位） | **27 位定点**用于相位/索引（scale≈2²⁷，`andl $0xfffffff`） |
| 输出 | 20 位样本 | int32（满量程 ±16.0 → ±2³¹）/ ±1.0 归一化 |

指令量（`.text`）：`mulss`×7619、`addss`×8016、`comiss`×888、`cvttss2si`×50、
`cvtdq2ps`×79、`cvtsi2ss`×25、`andps`×24、`orps`×14、`andnps`×1、`ucomiss`×1；
**`minps/maxps/minss/maxss/blendps/packssdw` = 0**。

> 要点：float 承载主运算（mulss/addss 占绝对主导），整数/定点只用于
> 相位、索引、量化。**float 范围比 20 位大 19 个数量级**，所以「溢出」在 VSTi
> 里几乎不发生——这是它和芯片边界行为最本质的差别。

## 3. 边界机制总览（限幅怎么做）

VSTi **不用 SIMD 饱和**，全部走**标量分支**：

```
comiss  <阈值>, %xmm0      ; 浮点比较，置 EFLAGS
jg/jb   <跳过>             ; 越界才跳
movl    $<钳位常数>, (%rcx) ; 写入钳位值（或 int32 极限）
```

两个实测限幅点：

**（A）±1.0 归一化限幅 —— `0x180006bdc`**
```asm
comiss  0x181a041a8, %xmm0   # 阈值 = +1.0
jbe     …
movl    $0x3f800000, (%rcx)  # +1.0f
retq
comiss  0x181a041dc, %xmm0   # 阈值 = -1.0
jae     …
movl    $0xbf800000, (%rcx)  # -1.0f
retq
```

**（B）int32 满量程饱和 + 量化 —— `0x180005ce4`**
```asm
comiss  0x181a041b8, %xmm0   # 阈值 = +16.0
jb      …
movl    $0x7fffffff, %eax    # INT32_MAX（越上界 → 钳到 +max）
…
comiss  0x181a041e8, %xmm0   # 阈值 = -16.0
ja      …
movl    $0x80000000, %eax    # INT32_MIN（越下界 → 钳到 -max）
…
cvttss2si %xmm0, %eax        # 截断 float→int（非四舍五入）
```
即：**内部样本满量程 = 16.0**（`±16.0 → ±2³¹`，4× 幅度 / 24 dB 余量），
越界先钳位、再 `cvttss2si` 截断。

**相位/索引的 27 位定点（50 处 `cvttss2si` 的统一形态）：**
```asm
mulss   0x181a041d0, %xmm0   # ×2²⁷（0x181a041d0 = 134217730 ≈ 2²⁷）
cvttss2si %xmm0, %eax
sarl    $0x4, %eax           # ÷16
andl    $0xfffffff, %eax     # 27 位掩码
```

## 4. 逐点对照：VSTi 边界 vs 芯片（pcm.cpp）边界

### 4.1 滤波器（每采样边界）

- **VSTi**：`state2 = state1·B + state2; out=state2; err=in−(state2+state1·A);
  state1 += err·B`。二阶双积分谐振低通，**纯 float、每采样不饱和、无 min/max**。
  两处实现：SIMD（`0x18008d9a0`，一次 4 声部，`mulps/addps/subps`）+ 标量
  （`0x18008ce70` 按 2-bit 状态分发到 `0x18008d0a0/d2d0/d520/d740`，仅输出抽头/
  系数取法不同）。详见 `scgs_filter.md`。
- **芯片**：`reg1`/`reg3` 两个积分状态，**每次加法都 `addclip20` 20 位饱和**、
  `multi` 做 20 位符号扩展 ×8 位 → 25 位。

> 结论：**拓扑一致（验证了 pcm.cpp 结构），边界行为相反**——芯片每加一饱和，
> VSTi 不加。系数拆分也不同（芯片 3 项入 s2 + 2 项入 s1；VSTi 2 系数 + 前馈项）。

### 4.2 饱和 / 限幅

| | 芯片 | VSTi |
|---|---|---|
| 手段 | `addclip20`（每加法显式 20 位饱和） | `comiss`+分支（标量），无 SIMD min/max |
| 滤波器内 | 有 | **无** |
| 输出 | 20 位 | ±1.0（归一化）/ ±16.0（int32 满量程） |

### 4.3 溢出

| | 芯片 | VSTi |
|---|---|---|
| 边界 | ±2¹⁹ = ±524288（**频繁到达**，是音色的一部分） | ±3.4e38（float，**几乎不到**） |
| 处置 | `addclip20` 钳到 0x7ffff / 0x80000 | 依赖 float 大裕量；int32 路径才钳 ±16.0 |

### 4.4 量化

- **VSTi**：`cvttss2si`（**截断**）；27 位定点（scale 2²⁷）做索引/相位。
- **芯片**：本身即定点，无「浮点→定点」量化步骤（`multi` 的 `>>6`/`>>13` 是
  定点移位缩放，等价于浮点乘常数）。

### 4.5 符号 / 扩展

- **VSTi**：float 自带符号位，无需手工符号扩展。
- **芯片**：`multi` 显式把 20 位符号位扩到 25 位（`if(val1&0x80000) val1|=~0x1ffffff`），
  这是芯片边界逻辑里最容易被移植搞错的一环。

### 4.6 NaN / Inf

- **VSTi**：全 DLL 仅 **1 个 `ucomiss`**，在 `TG_setSampleRate`
  （`0x180088bb0`）：比较新旧采样率（unordered = NaN 守卫），变化则调
  vtable[2] 全量重建。**每采样 DSP 无 NaN/Inf 防护。**
- **芯片**：定点无 NaN 概念（只有溢出→饱和）。

### 4.7 寄存器 / RAM 字宽（芯片「工作边界」的物理层）

- **芯片**：边界即 **20 位字**（`ram1[]`/`ram2[]` 每个值 0..0xfffff，符号 bit19）。
  MCU 与芯片的所有数据交换都是 20 位（或 8/16 位字段）。
- **VSTi**：边界即 **float32 样本** + **27 位定点索引**；没有「20 位字」这层约束。

## 6. 对 mk2 爆音（issue #101）的含义

**边界视角下的三方对比：**

| | 数值 | 滤波器饱和 | 边界电平 |
|---|---|---|---|
| 芯片 mk1（R15239148） | 20 位 | **每加一饱和** | **±524288**（常到） |
| 芯片 mk2 hack（pcm.cpp:1391+） | 32 位 int | **无** | ±2³¹（几乎不到） |
| **SC-GS VSTi** | float32 | 无 | ±3.4e38（几乎不到） |

- 芯片的饱和**不是 bug，是音色**：20 位在 ±524288 削顶，是 SC-55 声音的一部分。
- mk2 hack 把数值抬到 32 位（边界抬高 13 位）却**没补回饱和**。于是高谐振音符里，
  mk2 的滤波器状态会**越过 ±524288**——一个 mk1 芯片会削掉的电平——一直环到更高
  （直到 32 位或后级才削），听感即「爆音/过载」。
- VSTi（Roland 自家参考）**也不饱和**，但那是因为 **float 大裕量让饱和变得不必要**；
  芯片是因为 20 位**必须**饱和。两者「都不饱和」的**原因不同**。
- **推论**：若真 mk2 芯片（R15239229）仍是 20 位定点，则它**应当饱和**，mk2 hack 的
  「无饱和」就是错的 → 修法是**给 mk2 补回 20 位饱和**（对齐 mk1）。若 mk2 硬件换了
  更宽字长，则 hack 方向对、但 32 位仍比 float 窄 → 修法是**加宽累加（40+ 位）或改
  float 滤波**。**VSTi 本身在两种解释间不能拍板**，但它把「目标算法是未饱和形式」
  与「芯片因定点必须饱和」这两件事都摆到了明面上。

> 下一步最省事的验证：导出 VSTi 一个**干音**（单声部、关 chorus/reverb）与模拟器
> 一个干音，逐采样 diff——能直接看到滤波器边界（饱和 vs 未饱和）在尾部/峰值的差异。

## 7. 局限

- **软参考**：float32 vs 20 位定点，**不能逐采样 A/B mk2**，只能看趋势/结构。
- 系数（`A`/`B`）的**实际数值**在 DLS 参数更新路径里，本文只确认了边界，未逐值提取；
  与芯片 `ram2[11]` 那条链的逐值对齐是后续工作。
- VSTi 的 chorus/reverb 是 **DLS 标准**，非 SC-55 芯片版——「气质不对」的另一来源，
  不在「工作边界」范畴内，单列。
