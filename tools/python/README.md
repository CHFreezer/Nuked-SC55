# tools/python

Embedded CPython 3.11 runtime (self-contained, no install needed).

Used by `../build/dasm.py` (the Python disassembler) during the investigation.
The whole directory is gitignored except this note, which is tracked so git
keeps the folder in place. If you need the runtime, download a Windows
embeddable package and extract it here (must contain `python.exe`).
