# mk2cpp 架构（修订 2026-09-11：库集成，非独立 exe）

> **架构修订（用户指令）**：产物是 **`mk2cpp.h` 库**，编译进 GT，**替换原 H8 解释器行为**；
> 不做独立 `mk2cpp.exe`。设备/调度/音频全部复用 GT，翻译代码直接操作 GT 全局状态，
> 通过开关启用、未翻译 PC 自动回退解释器（混合模式）。

## 1. 总览

```
+---------------------- GT (nuked-sc55.exe) ----------------------+
| work_thread 调度（顺序不变）                                    |
|   中断轮询 -> 取指/执行 -> cycles+=12 -> PCM_Update -> TIMER... |
|                                                                |
|   if (mk2cpp_enabled && MK2CPP_CanStep(pc))                     |
|        MK2CPP_Step();          // 翻译代码：恰好一条指令的语义    |
|   else                                                         |
|        MCU_ReadInstruction();  // 原解释器（回退/对照）           |
|                                                                |
|   设备模型：src/pcm.* mcu_timer.* submcu.* lcd.*（原样复用）      |
+----------------------------------------------------------------+
        ^ mk2cpp.h 暴露的 ABI（无独立运行时、无独立内存）
        |
+-- mk2cpp 产物 -------------------------------------------------+
| src/gen/*.cpp（本地生成，不入 git）：按 PC 分派的翻译实现        |
| src/hand/*.cpp（入库）：人工语义化改写（M4 voice/PCM）           |
| mk2cpp/mk2cpp.h（入库）：开关/初始化/单步/覆盖率钩子 API         |
+----------------------------------------------------------------+
```

## 2. 集成 ABI（`mk2cpp/mk2cpp.h` 草案）

```c
// 全局开关由命令行/配置设置；默认关闭时 GT 行为与 stock 完全一致
extern int mk2cpp_enabled;      // -mk2cpp 打开
extern int mk2cpp_mixed;        // 1=未翻译 PC 回退解释器（M1/M2 默认）

void MK2CPP_Init(void);                 // 加载/初始化翻译表（无 ROM 依赖的动态注册）
int  MK2CPP_CanStep(uint32_t cp_pc);    // 该地址是否已有翻译实现
void MK2CPP_Step(void);                 // 执行一条翻译指令（等价 MCU_ReadInstruction）
const char *MK2CPP_Version(void);       // 生成集版本 + ROM sha256（诊断）
```

- **执行粒度 = 一条指令**：保证与 GT 的每指令中断轮询/`ex_ignore`/`STATUS_T` 时序一致
  （`src/mcu.cpp:1343-1351`）。块级批处理只能作为后续优化，且必须实现
  `RT_PostInstr` + `irq_abort`（见 06 设计）后再启用。
- **内存/IO/标志**：翻译代码直接调用 GT 的 `MCU_Read/Write`、`MCU_SetStatus*`、
  栈/控制寄存器函数（`src/mcu.h`、`src/mcu_opcodes.cpp`），不复制一套。
- **回退**：`MK2CPP_CanStep` 为假时 GT 调 `MCU_ReadInstruction()`；两者同一 `mcu` 状态。
- **诊断**：可统计 fallback 次数与 PC 直方图（写 `mk2cpp/out/`，本地）。

## 3. 生成代码形态（`src/gen/`，本地，不入 git）

- 每个执行 PC → 一个函数（或按块函数 + 块内 goto；实施以 06 设计为准）：
  `void mk2c_r1_0000F86(void);`，函数体为精确的 GT 语义步，结尾写回 `mcu.pc/cp`。
- 分派：两张 64KB 表 `mk2cpp_tab_cp0/mk2cpp_tab_cp4`（函数指针，未翻译为 NULL），
  由 `mk2cpp.cpp` 持有；`MK2CPP_CanStep` 查表。
- 生成文件头：`// GENERATED by h8lift <ver>; ROM sha256 <...> -- DO NOT EDIT`。

## 4. 构建集成

- GT `CMakeLists.txt` 增加可选源：`MK2CPP_GEN_DIR`（默认空 → 不编译生成物，
  GT 行为不变）；`mk2cpp/mk2cpp.cpp` 与小工具仅在开关打开时参与。
- 生成物**不提交**（ROM 派生）；新克隆默认无翻译代码，纯 stock 行为。
- 本地构建：`cmake -DMK2CPP_GEN_DIR=mk2cpp/src/gen ...` 后正常 build。

## 5. 验证（详见 04，按集成修订）

- 对照 = **同一 GT 二进制两种模式**（默认解释器 vs `-mk2cpp`），同输入、同窗口：
  trace / 快照 / 设备寄存器 / 音频哈希逐项比对；分歧用 04 的 triage 流程。
- M1 首个 oracle：`-tracepc` boot 0–3M 与 `tools/baselines/trace_boot3m_base.txt`
  逐行 0 分歧；再扩到 200M–202M 快照窗口。
- 在线双核（同进程 lockstep）**不需要**：同二进制两模式 + 离线 diff 即可达到目的；
  若要在线，需为两核复制全部 GT 全局状态，收益低、风险大（04 §2 记录）。

## 6. 目录职责

| 目录 | 内容 | 入 git |
|---|---|---|
| `mk2cpp/include/mk2cpp.h` | 集成 ABI（公共头） | 是 |
| `mk2cpp/src/mk2cpp.cpp` | 分派表/回退统计/版本（薄层） | 是 |
| `mk2cpp/tools/h8lift` `tools/tracediff` `tools/cover` | 工具源码 | 是 |
| `mk2cpp/src/hand/` | 人工语义化改写（M4） | 是 |
| `mk2cpp/src/gen/` | 自动翻译产物（ROM 派生） | **否**（本地，CMake 可选） |
| `mk2cpp/tests/` | 脚本入库；语料/快照本地 | 部分 |
| `mk2cpp/out/` | 运行产物 | 否 |

命名：集成开关/符号统一 `mk2cpp`/`MK2CPP_`/`mk2c_` 前缀（不使用 `h8cpp`——本工程
翻译的是 MK2 ROM，不是重写 CPU 核；GT 本身可跑多种固件）。
